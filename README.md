# Sean MacMannis

Personal portfolio for seanmacmannis.com.

## Site

The complete static site is in `dist/`. Edit `dist/index.html`; photos are in `dist/assets/`. No installation or build step is required.

## Cloudflare Pages

- Production branch: `main`
- Framework preset: None
- Build command: leave empty
- Build output directory: `dist`

Connect this repository to Cloudflare Pages for automatic deployments on pushes to main. Add the custom domain in Cloudflare after the first successful deployment.

The ChatGPT Sites hosting manifest and credentials are intentionally excluded.
